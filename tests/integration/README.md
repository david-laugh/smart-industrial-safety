## 입력 데이터 원칙

- 실제 작업자 이미지를 쓸 경우 촬영 동의와 보관 정책을 따른다. 저장소에는 커밋하지 않는다.
- 반복 가능한 재생 입력(고정 JPEG 시퀀스)과 실기 입력을 모두 사용한다.
