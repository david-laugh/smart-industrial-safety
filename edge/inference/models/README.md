# edge/inference/models/ — 모델 가중치 위치 (비어 있음)

담당: **B (AI / Vision)**

- 이 디렉터리에는 모델 가중치를 **커밋하지 않는다** (`*.onnx`, `*.ort` 등은 `.gitignore` 대상).
- 배포 시 모델 파일은 별도 경로(`MODEL_DIR`)에서 읽기 전용으로 마운트한다.
- 배포에 쓰는 모델은 이름·버전·sha256을 모델 카드와 `INFERENCE_MODEL_SHA256`에 기록하고, 이벤트의 `model` 필드와 일치해야 한다.
- 모델 배포 저장소(예: 릴리스 아티팩트, 오브젝트 스토리지)는 구현 단계에서 B와 D가 결정한다.
